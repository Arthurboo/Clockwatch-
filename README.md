# Clockwatch

A simple countdown timer website. Starts at 5 minutes, and you can click the numbers to change the time.

## Features

- Countdown with a ring that shrinks as time runs out
- Start / Pause / Resume and Reset buttons
- Click the time (when the clock is not running) to edit it
  - Type `7:30` for 7 minutes 30 seconds, or just `10` for 10 minutes
  - Press Enter to save, Escape to cancel
- Beep and a message when time is up
- Light and dark mode

## How to run

Open `index.html` in any web browser. No installs needed.

## Built with

Plain HTML, CSS and JavaScript (one file).
